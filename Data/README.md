## Data Source

This project uses publicly available behavioral data collected by Ben-Artzi et al. (2023), obtained from the Dryad Digital Repository.

The dataset contains trial-level behavioral responses from a multi-armed bandit task and is used here for an independent hierarchical Bayesian analysis of reinforcement learning.

The original data were not collected by the author of this repository.

**Data license:** CC0 1.0 Universal Public Domain Dedication.

**Dataset citation:**

Ben-Artzi, I., Kessler, Y., Nicenboim, B., & Shahar, N. (2023). Computational mechanisms underlying latent value updating of unchosen actions [Dataset]. Dryad. https://doi.org/10.5061/dryad.d51c5b08d

**Original publication:**

Ben-Artzi, I., Kessler, Y., Nicenboim, B., & Shahar, N. (2023). Computational mechanisms underlying latent value updating of unchosen actions. *Science Advances, 9*(42), eadi2704. https://doi.org/10.1126/sciadv.adi2704
